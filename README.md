
🍔 FastFood Store Web Application
📌 Giới thiệu

FastFood Store Web là ứng dụng web mô phỏng hệ thống quản lý cửa hàng thức ăn nhanh. Dự án tập trung vào phân tích nghiệp vụ, thiết kế chức năng, mô hình dữ liệu, UI/UX và kiểm thử, đồng thời thực hành Java Backend, SQL Server và Frontend React.
